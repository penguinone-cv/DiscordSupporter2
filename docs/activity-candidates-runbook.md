# 候補日 Activity 作業手順

1. 最新mainを取得し codex/activity-candidate-calendar を作成する。
2. 仕様書 → 本手順書 → タスク分解の順で文書化する。
3. タスクごとに失敗するテストを追加し、Redを確認、実装、Green、差分レビューを行う。
4. 集計・API、UI、導線の順で実装する。既存の認証・募集サービスを共用する。
5. npm test と npm run build:activity を実行し、全体差分と旧文言を確認する。
6. 既存のActivity配信方法でビルドを配置しBotを再起動する。設定・URLマッピング変更は不要。
7. Discord内で共通入口、両タブ、月・ゲーム選択、人数と名前、募集投稿、重複、既存リアクションを確認する。通常ブラウザだけでは完了判定しない。
8. 不具合時は従来表示を利用し、必要なら変更前のアプリケーションに戻す。DB復元は不要。

本作業中は本番へのデプロイや実募集は行わず、実機確認未実施ならレビュー記録に残す。
