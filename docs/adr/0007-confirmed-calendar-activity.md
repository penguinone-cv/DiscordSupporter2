# ADR-0007: 確定済み予定カレンダーを共通Activityへ統合する

- 日付: 2026-10-01
- 状態: Accepted
- 対応する正本: [APP-06/07](../spec/application.md)、[テスト方針](../spec/testing.md)

## 目的と仕様

予定入力・候補日確認／募集投稿と、リマインドから登録された確定済み予定の確認を同じActivityで行えるようにする。共通入口に「確定済み予定」タブを追加する。ユーザーの統合・PR作成依頼に基づく。

- 入力: Activityの署名済みセッション、表示年月（省略時はサーバーの今月）、任意のチャンネルID。
- 出力: サーバーのタイムゾーン・今日・表示年月、閲覧可能なチャンネル、月内の確定済み予定。チャンネル選択時には同名ロール／ゲームの保存済みロールのメンバーに関連する他チャンネルの予定とメンバー名も表示する。
- 保存元は `reminderService.getCalendarEvents()`。待機中のリマインド一覧を使わず、通知後に保持される予定と過去月も閲覧する。JSONの移行や通知処理の変更は不要。
- 現所属と起動元サーバーを既存Activity認証で確認する。チャンネル閲覧・メッセージ履歴権限のない予定、他サーバー、削除済みチャンネルは表示しない。絞り込みは名前ではなくIDで行う。
- 日曜始まりの7列、前月／翌月／今月、チャンネル絞り込み、日付詳細で内容と関連メンバー名を確認する。日付はUTC文字列の先頭ではなくサーバーのタイムゾーンで判定する。リマインド時刻は開始時刻として扱わない。
- 5秒更新・手動更新、非表示／縮小時の停止、タブ切替時の破棄、古い応答の破棄を既存Activityと揃える。
- ライブラリは既存のExpress、Discord.js、Vite、DOM表示ヘルパーを使用し追加依存を導入しない。
- 例外: 不正な年月・入力は400、閲覧不可の選択チャンネルは404。認証失敗時は表示データを消し、通信失敗時は再試行を案内する。外部通信や内部情報を含む例外本文を返さない。

## 検証

HTTP認証・所属／チャンネル権限・他サーバー分離、通知済み予定保持、タイムゾーンと年越し、関連メンバー表示を検証する。UIでは3タブの導線、内容の安全な表示、月・チャンネル切替と古い応答、縮小／破棄時の更新停止、認証失敗後の表示消去を守る。既存の予定編集・募集のテストとActivityビルドを実行する。Discord実機のレイアウト確認は別途必要。
